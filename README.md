# 底値日数チェッカー

入力した国内証券コードの株価が、指定金額以下だった連続期間を探すアプリです。証券コードの初期値は日産自動車（7201）です。

## 起動方法（Windows）

1. Python 3.10以上をインストールします。
2. `start_app.bat` をダブルクリックします。
3. 初回だけ必要な部品を自動インストールした後、ブラウザでアプリが開きます。

画面左側に証券コードと「XX円」を入力し、「集計する」を押してください。判定には各取引日の安値を使います。

## 結果の意味

- 下回った日数: 開始日から終了日までを土日・祝日込みで数えた日数。
- 一覧は開始日の新しい順です。
- 結果はExcelで開けるCSVとして保存できます。

Yahoo Financeから日足を自動取得します。
